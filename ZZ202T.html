生活不总是充满阳光，、大火、水灾等往往不请自来，把准备的人类推到的面前。在紧急的情况下，如果人们处理危机的知识和，就有可能保护自己，减少死伤。相反，则想象。


下面，我们就几种紧急情况，并两种不同的方法让你选择，以此来考考你的生存知识和生存技巧。


📝句子排序：把本段句子调整为课文正确顺序
Q1：危机到来的时候，具备生存知识有什么作用？
具备生存知识与技巧，可以保护自己，减少死伤；没有相关知识，后果难以想象。

一、地震刚刚发生的时候，建筑大约要一分钟左右，如果你正待在家里，正确的做法是：A赶快钻进比较的桌子下、床下或者高大的里面躲起来，被高处掉下来的东西和倒下来的家具伤。B迅速跑到承重墙的墙角、厕所等比较小的房间里。


二、在地震暂时停止或发现高层楼房要倒下去的时候：A 快速跑走，或者抱着被子从窗户往下跳。B 如果住在高层，跑楼梯被撞伤摔死，留下来躲好。能快速跑到外面，才向外跑。跑出来后别站在楼房旁边。


📝句子排序：把本段句子调整为课文正确顺序
Q2：地震发生时，为什么不能站在柜子旁边？
地震时柜子可能倾倒，柜子或者掉落物品会砸伤人。

三、如果已经被困在楼房里或埋在下，短时间找不到支援的人。A大声喊叫。B尽可能让自己保持；必要时敲打物体求救，等待救援。


四、楼内突然起火、很大时。A直接穿过烟雾区逃离。B脱下衣服或者找到毛巾，湿后多几层，放在口鼻上，避免吸入，防止不能呼吸而死去。


📝句子排序：把本段句子调整为课文正确顺序
Q3：火灾里面，湿毛巾有什么作用？
湿毛巾可以过滤有害气体烟雾，保护人的呼吸。

五、逃离烟雾区，正确身体：A直起身子大步往前跑。B尽量低头弯腰往前跑，靠近地面空气比较。


六、半夜起火被大火包围：A向着有光亮的地方跑。B不要朝光亮跑，大火后很可能被切断，光亮代表着火。


七、碰到发大水：A会游泳就拼命地出危险区。B迅速向、高地楼房，耐心等待帮助。


八、出门碰到大水：A着水流方向跑。B朝着水流两边跑，尽快开大水，才被大水冲走。


📝句子排序：把本段句子调整为课文正确顺序
Q4：遇到洪水，为什么不能顺着水流跑？
顺着水流跑很容易被洪水冲走，要向两侧高地躲避转移。

经验证明，A与B两种方法中，B的选择更正确，因此也最容易逃生成功。生活里的紧急情况远这八种，在你的一生中会遇到这样或者那样的危机。请问，你这些生存知识和逃生技巧吗？相信你一定会想办法了解和学会的，因为人的生命太宝贵了，需要永远和珍惜它。

Q5：读完全文，说一说学习生存技巧有什么意义？
遇到灾难危机的时候，可以保护自己的生命，减少伤害，学会尊重珍惜生命。

1. 在……的情况下 【HSK4 条件格式】

说明某种处境、条件。
格式：在+某种情况+的情况下，+结果句子。

⚠易错：后面句子一般写现实、假设发生的事情，不写命令。

例句：在万分紧急的情况下，人们要保持冷静。

补全句子：用“在……的情况下”写一个遇到危险的句子。
示例：在火灾发生的情况下，我们不要慌张。
2. 难以 + 动词 【HSK5】

表示“很难做某事”，后面直接接双音节动词。

⚠易错：后面不能接单字动词；不能说“难以跑”，要说“难以逃跑”。

例句：灾难带来的破坏，让人难以想象。

补全句子：用上“难以”写句子，写一件很难做到的事。
示例：当时情况很乱，真相难以查清。
3. 相反 【HSK5 转折连词】

用于前后两件事对比，后一件和前面完全不一样。放在句子开头。

⚠易错：“相反”后面一般有逗号。

例句：有知识可以保护自己。相反，无知会带来危险。

补全句子：用“相反”写一组对比。
示例：认真准备会减少麻烦，相反，毫无准备会遇到很多困难。
4. 以此来 【书面 HSK5】

“用前面这件事，来实现后面的目的”。

例句：我们做练习，以此来巩固学到的生词。

补全句子：用“以此来”写目的。
示例：我们学习自救知识，以此来保护自己。

1. 以免 【HSK5 目的连词】

前面做动作，目的是避免后面坏事发生。格式：动作 + 以免 + 不好结果。

⚠易错：后面直接写短句，不能加主语。

例句：躲到安全地方，以免被东西砸伤。

补全句子：用“以免”写一个安全提醒。
示例：远离燃烧的火，以免被烧伤。
2. 与其……宁可…… 【HSK5 选择复句】

比较两件坏事，情愿选择后者。
格式：与其+不希望的事，宁可+相对可以接受的事。

⚠易错：两件事一般都是不好的情况。

例句：与其冒险跑出去，宁可留在原地等待救援。

补全句子：用“与其……宁可……”写句子，说说你的选择。
示例：与其冒雨赶路，宁可多等一会儿雨变小。
3. 除非……才…… 【HSK5 条件复句】

“除非”引出唯一必要条件，满足条件，后面“才”的事情才可以做。

⚠易错：条件不满足，就不能做“才”后面的动作。

例句：除非确认环境安全，我们才可以离开。

补全句子：用“除非……才……”写条件。
示例：除非做好准备，我们才可以开始这项工作。
4. 大约 + 时间/数量 【HSK4】

表示估计、大概的数字，不精确。

例句：地震摇晃大约一分钟左右。

补全句子：用“大约”写一个估计时间。
示例：走路到那里，大约需要二十分钟。

1. 导致 【HSK5 动词】

动词，多半引出不好的结果。格式：原因 + 导致 + 坏结果。

⚠易错：“导致”前面是原因，后面是结果；不能用于好事情。

例句：吸入浓烟会导致人昏迷。

补全句子：用“导致”写一个不好的结果。
示例：错误的做法会导致严重的后果。
2. 尽可能 【HSK5 副词】

表示尽量、尽最大努力去做。放在动词前面。

例句：被困的时候，尽可能让自己保持冷静。

补全句子：用上“尽可能”写一个建议。
示例：遇到危险，尽可能快速离开危险区域。
3. 多 + 量词 + 几 + （名词）【HSK4】

表示数量增加几层、几件等。课文：多叠几层。

⚠结构：多 + 动词 + 几 + 量词。例：多写几遍，多看几眼。

例句：把毛巾多叠几层，可以更好过滤烟雾。

补全句子：用“多……几……”写句子。
示例：这个生词很难，你要多读几遍。
4. 避免 + 动词短语 【HSK5】

“不要让不好的事情发生”，后面直接接行为。

⚠易错：避免后面不加主语。

例句：捂住口鼻，避免吸入有害气体。

补全句子：用“避免”写安全提示。
示例：走路注意脚下，避免摔倒受伤。

1. 不至于 【HSK5】

表示情况不会坏到某种地步。格式：主语 + 不至于 + 不好情况。

⚠后面一般接动词/形容词，多用否定推测。

例句：学会自救，不至于完全慌乱。

补全句子：用“不至于”写一句话。
示例：提前做好准备，我们不至于手忙脚乱。
2. 尽量 【HSK4副词】

表示尽力去做，放在动词前。课文：尽量低头弯腰往前跑。

例句：遇到危险，我们尽量保持冷静。

补全句子：用上“尽量”写建议。
示例：考试的时候，尽量把字写清楚。
3. 很可能 【HSK4 推测短语】

对事情做推测，“可能性比较大”。课文：电源很可能被切断。

⚠放在动词前面。

例句：大火之后，电路很可能出现问题。

补全句子：用“很可能”写推测。
示例：这么晚了，他很可能不会回来了。
4. 向 + 地点 【HSK4 方向介词】

表示动作朝向某个地方：向山坡、向高处。

⚠“向”后面接方位、地点名词。

例句：遇到洪水，迅速向高地转移。

补全句子：用“向”写移动方向。
示例：听到声音，大家向门口跑过去。

1. 八成 【HSK5 副词（表推测）】

口语书面都可用，“多半、大概率”，用来推测事情。

⚠只用于推测，不表示精确的数字。

例句：这么做，八成会带来伤害。

补全句子：用“八成”写推测的句子。
示例：天上乌云很多，八成要下雨。
2. 远不止 【HSK5】

“远远超过，不只是”。课文：紧急情况远不止这八种。

“远”加强程度，不止+数量/名词。

例句：需要学习的知识远不止课本上面的内容。

补全句子：用上“远不止”。
示例：生活中的困难远不止我们看到的这些。
3. 因为……，所以…… 【HSK2 因果复句】

说明原因与结果。课文：因为人的生命太宝贵了，需要永远尊重和珍惜它。

有时候“所以”可以省略，只保留“因为”。

例句：因为危机很可怕，所以我们要学习生存技巧。

补全句子：用“因为……，所以……”写因果。
示例：因为生命只有一次，所以我们要好好保护自己。
4. 相信……一定会…… 【HSK4】

表达对未来的信心，相信后面是句子。

例句：相信你一定会学会这些自救的本领。

补全句子：用“相信……一定会……”写信心。
示例：相信只要努力，你一定会取得进步。
