📖语法综合练习（本篇 HSK4‑HSK5 语法点）

1.【补全句子】“虽然……但是……”：__________，但是桑兰从来没有叫疼。
参考答案：虽然身上非常疼
2.【修改病句】改正下面句子：“桑兰受伤以后，她的全身80%地方没有感觉仍然。”
参考答案：桑兰受伤以后，她的全身80%地方仍然没有感觉。
3.【调整词语顺序】重新排列词语组成通顺句子：战胜 / 每天 / 各种各样的困难 / 桑兰 / 需要
参考答案：桑兰每天需要战胜各种各样的困难。
4.【补全句子】“正是由于……，……”：正是由于桑兰的坚强，__________。
参考答案：她被评为“年度英雄”
5.【修改病句】改正：“成千上万人们关心着受伤的桑兰。”
参考答案：成千上万的人们关心着受伤的桑兰。
6.【调整语序】重组：回报 / 要 / 桑兰 / 社会 / 把得到的爱
参考答案：桑兰要把得到的爱回报社会。
7.【补全句子】“不曾”：受伤之后，桑兰__________真正放弃希望。
参考答案：不曾
8.【修改病句】改正：“桑兰把仪器捐医院全部。”
参考答案：桑兰把仪器全部捐给医院。
9.【补全句子】“如同……一样”：时间__________，十一年很快过去了。
参考答案：如流水一样
10.【调整语序】重组：应邀 / 桑兰 / 很多工作 / 为奥运会 / 做了
参考答案：桑兰应邀为奥运会做了很多工作。
11.【补全句子】“无论……总……”：__________多么艰难，总有一种精神支持桑兰。
参考答案：无论

1998年7月，桑兰到美国参加第四届友好运动会。作为国家队运动员，她已经多次获得过跳马冠军，因此，她对即将开始的比赛充满。


谁也没想到，意外发生了：在赛前练习时，她头朝下，重重地摔到地上，伤得非常严重，双手、胸部以下什么感觉都没有了。只短短的几秒钟，一切都改变了。刚刚还是健康、充满活力的运动员，不幸却一下子落到她的头上。7月21日，成为桑兰中永远不愿意再提起也永远不可能忘记的一天。


她立即被送到纽约一家医院。六天后，在中心接受了七个小时的手术。当桑兰重新出现在大家面前时，人们发现，虽然她的头被铁着，鼻子里、手上挂满了，但是她依然在笑，笑得那么甜，那么自然，那么灿烂！


遇到这样大的打击，难道她就没害怕过吗？桑兰后来告诉记者，刚刚从手术中醒过来的那一刻，她过，“我真的感觉很痛苦。想动也动不得，想翻身也翻不得，一夜一夜地睡不着。”然而，桑兰从来不叫疼，更不会流眼泪。

Q1：意外发生在什么时候？什么地方？
1998年7月，在美国第四届友好运动会赛前练习的时候。
Q2：发生了什么样的意外？
赛前练习时，她头朝下，重重地摔到地上，伤得非常严重，双手、胸部以下什么感觉都没有了。
Q3：为什么桑兰不愿意再提起7月21日这一天？
就在这一天，严重的意外发生在她身上，健康的她受了重伤。
Q4：桑兰最初是在哪家医院治疗的？
纽约一家医院。
Q5：治疗时和治疗后的情况怎么样？
六天后接受七个小时手术；头被铁架子固定，身上挂着仪器，但她依然笑得很甜很灿烂。
Q6：桑兰刚从手术中醒来时告诉记者什么？
她绝望过，感觉很痛苦，想动、想翻身都做不到，一夜一夜睡不着。

桑兰在不幸面前露出的，感动了所有看到她的人。为她治病的医生说：“从这个小姑娘身上，我看到了勇气。”很多人都相信：她一定会走出这场可怕的灾难！


十个月后，桑兰从美国回到中国继续进行。时间如流水，十一年过去了。桑兰的微笑仍然挂在脸上，笑容仍然那么灿烂。人们也许会问，在她伤后这十年里，那微笑的背后究竟还藏着什么？


微笑背后当然有平常人不能了解的。桑兰从一个每天只参加训练的运动员，变成了随时都要考虑“自己未来怎么生活下去”的人。手术虽然让桑兰活了下来，但是到现在，她全身80%的地方仍然没有感觉，失去了大部分的活动能力。她的双手改变了形状，右手摸到头顶。


她想靠自己翻身，却翻不得；想靠自己的力气从里移到床上，却移不得。她的手指还是不能动，手被热水烫坏了她都不知道。日常生活的小事随时跟她过不去。就拿在家来说吧，正常高矮的电灯开关，在桑兰看来太高了，根本够不着。厨房的比低，轮椅进去就出不来。

Q7：桑兰受伤后表现得怎么样？
虽然经历巨大不幸，但她仍然露出微笑，不叫疼，不当众流眼泪。
Q8：人们怎样评价桑兰的表现？
医生说从小姑娘身上看到勇气；很多人相信她可以走出灾难。
Q9：桑兰回国后一直到现在，她的情绪好吗？

Q10：在桑兰微笑的背后，首先碰到什么问题？请举例说明。
有着平常人难以了解的艰难；例如身体大部分没有知觉，很多日常动作自己做不了。
Q11.“翻不得”、“移不得”是什么意思？
不能够翻身，不能够移动。
Q12.“跟她过不去”是什么意思？
很多生活小事为难她，给她带来麻烦。

用力过大，轮椅就有可能向后翻过去……在家如此，出门坐火车、乘飞机、住旅馆、上大学，要完成这些复杂的活动该有多么艰难就可想而知了。对于桑兰来说，她每天需要的困难，都是在平常人看来再容易不过的小事情。


微笑背后肯定有勇气。回国后，桑兰不愿意像病人般地待在家里，一直坚持康复训练。现在，她手上戴上工具，可以自己吃饭、洗脸、刷牙、穿衣服，还学会了使用电脑。她选择到北京大学学习新闻，一学就是五年。她最喜欢的生日礼物是一位送给她的一画，那是一只很可爱的小，脸上透着一倔劲。


她之所以喜欢这幅画，就因为喜欢小毛驴的性格。她说：“永不放弃是一种精神。我就不信我活不出个美丽的明天。”正是由于桑兰的坚强和勇气，就在她受伤的当年，被美国最有影响的《》和《生活》为“”，还接受过《妇女体育》杂志她的“勇敢奖”。

Q13.桑兰在日常生活中到底遇到了什么样的困难？

Q14.桑兰坚持康复训练后，她能自己做什么？

被评为“年度英雄”，还被授予“勇敢奖”。

微笑背后有大爱，也有责任。桑兰忘记过，在她受伤后，她得到过社会各界人的关心和照顾。受伤以后，桑兰觉得给她支持最大的人是谢晓红女士。她不仅为桑兰了在国内治疗和教育用的全部费用，而且当她最困难的时候，他们一家人照顾她。


桑兰觉得应该把自己得到的一切给社会，尤其是要为8700万中国人多做一些事情。1999年回国时，桑兰把送给她的价值100多万元的治疗仪器，全部给了一家医院。


她每年都要跟着中国发展会到地区，去帮助那里的孩子们。她了一只名叫“同同”的母熊猫，希望它生出熊猫宝贝。

1. 虽然……但是…… HSK4转折

承认前面事实，后面出现相反情况。

“虽然”放前分句，“但是”放后分句。

例句：虽然身上十分痛苦，但是桑兰没有当众哭。

补全句子：虽然受了很重的伤，__________。
示例：但是桑兰仍然露出微笑。
2. 成为 HSK4动词

成为 + 名词。

例句：7月21日成为桑兰一生难忘的日子。

补全句子：这次意外__________她很难忘记的经历。
示例：成为
