重新（chóng xīn）｜频率副词 HSK4

【使用范围】

再一次从头做某件事，把之前做过的重做一遍。

【常用句式】

重新 + 动词短语

【例句】

1.写错了，请重新写一遍。

2.他决定重新开始学习。

【使用限制（易错点）】

放在主语后、动词前；表示动作再次重来，不是简单重复。

【常见错误】

✖重新作业。 ✔重新写作业。

✖重新我读。 ✔我重新读一遍。

往往（wǎng wǎng）｜频率副词 HSK4

【使用范围】

根据经验，事情常常这样发生，带有规律性。

【常用句式】

主语 + 往往 + 动词/形容词

【例句】

1.冬天这里往往会下雪。

2.周末他往往在家休息。

👆点击卡片翻转
【使用限制（易错点）】

用于客观经验、习惯；不用于未来一次性事件。

【常见错误】

✖明天往往下雨。 ✔春天往往下雨。

✖往往我早起。 ✔新年第一天我往往会早起。

偶尔（ǒu ěr）｜频率副词 HSK4

【使用范围】

不是经常，间或、有时候发生，次数少。

【常用句式】

主语 + 偶尔 + 动词；也可句首

【例句】

1.我偶尔去看电影。

2.偶尔我会不吃早饭。

👆点击卡片翻转
【使用限制（易错点）】

表示发生频次低；和“经常”语义相反。

【常见错误】

✖偶尔跑步每天。 ✔我偶尔跑步。

✖偶尔热闹。 ✔这里偶尔很热闹。

再次（zài cì）｜频率副词 HSK4

【使用范围】

再一次，动作又发生一次，书面口语都可用。

【常用句式】

再次 + 动词短语

【例句】

1.欢迎再次来到这里。

2.问题再次出现了。

👆点击卡片翻转
【使用限制（易错点）】

指动作重复发生；侧重又一次发生，不一定重做。

【常见错误】

✖再次作业。 ✔再次检查作业。

✖再次我提问。 ✔我再次提出问题。

【使用范围】

口语，总是、经常，动作频繁发生。

【常用句式】

主语 + 老 + 动词短语

【例句】

1.他老忘带钥匙。

2.机器老出问题。

【使用限制（易错点）】

仅限口语；“老”做副词≠年纪大；只能放在动词前。

【常见错误】

✖老他迟到。 ✔他老迟到。

✖老美丽。 ✔老发生这种情况。

【常用句式】

主语 + 故意 + 动词短语

【例句】

1.他不是故意弄坏的。

2.不要故意打扰别人。

【常见错误】

✖故意他吵闹。 ✔他故意吵闹。

✖故意开心。 ✔故意生气。

互相（hù xiāng）｜方式副词 HSK4

【使用范围】

双方彼此之间，你对我、我对你。

【常用句式】

复数主语 + 互相 + 动词

【例句】

1.同学之间互相帮助。

2.我们互相学习。

👆点击卡片翻转
【使用限制（易错点）】

主语必须是两个人或多个人；不能用于单人。只能做副词，不能修饰名词。

【常见错误】

✖我互相学习。 ✔我们互相学习。

✖互相朋友。 ✔朋友互相支持。

相互（xiāng hù）｜方式副词 HSK4

【使用范围】

义同“互相”，书面色彩更强，彼此双向。可作副词，也可作形容词修饰名词。

【常用句式】

复数主语 + 相互 + 动词；相互 + 的 + 名词

【例句】

1.两国相互尊重。

2.大家相互理解。

👆点击卡片翻转
【使用限制（易错点）】

多用于书面；主语必须是多方；可以修饰名词。

【常见错误】

✖我相互帮忙。 ✔大家相互帮忙。

✖相互吃饭。 ✔相互交流想法。

辨析：互相 VS 相互｜HSK4

【相同点】

作副词放在动词前，表彼此双向，大多可以互换。

同学们互相帮助 = 同学们相互帮助

【记忆口诀】

动词前面，互相、相互都可以；

修饰名词，只能用相互。

口语多用互相，书面多用相互。

👆点击卡片翻转
【核心区别】

互相：只能是副词，只能修饰动词，不能修饰名词，偏口语。

相互：副词+形容词；可以修饰名词：相互的关系、相互作用，偏书面。

【正误对比】

✔他们互相学习。

✔他们相互学习。

✖处理好互相的关系。

✔处理好相互的关系。

却（què）｜关联副词 HSK4

【使用范围】

表示转折，事情跟预想不一样。

【常用句式】

前小句，主语 + 却 + 小句

【例句】

1.天很冷，他却只穿一件衣服。

2.这件东西不贵，却很好用。

👆点击卡片翻转
【使用限制（易错点）】

放在主语之后；表转折，语义类似“但是”，是副词不是连词。

【常见错误】

✖却他不来。 ✔大家都来了，他却不来。

✖却我喜欢。 ✔很难看，我却很喜欢。

也许（yě xǔ）｜情态副词 HSK4

【使用范围】

猜测、可能性，或许、可能。

【常用句式】

也许 + 小句；主语 + 也许 + 动词

【例句】

1.也许明天会下雨。

2.他也许已经回家了。

👆点击卡片翻转
【使用限制（易错点）】

表示不确定推测；可以放在句首或者主语后面。

【常见错误】

✖也许明天的雨。 ✔也许明天会下雨。

✖也许他回家。 ✔他也许回家了。

恐怕（kǒng pà）｜情态副词 HSK4

【使用范围】

推测，多半，常常带有担心的语气。

【常用句式】

恐怕 + 小句

【例句】

1.时间太晚，我们恐怕来不及了。

2.这件事恐怕没有那么简单。

👆点击卡片翻转
【使用限制（易错点）】

说话人主观推测，常暗含担忧；多放句首或主语后。

【常见错误】

✖恐怕他的迟到。 ✔他恐怕要迟到。

✖恐怕下雨的。 ✔恐怕要下雨。
