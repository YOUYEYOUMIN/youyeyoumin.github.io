捡来的快乐｜课文交互学习

一个春天的上午，课间的时候，一个十岁左右的小男孩儿捧着一大把，来到我们农民工子弟学校办公室。他直接走到一位年轻漂亮的女老师身旁说：“老师，送你花儿。”那位年轻的女老师地抬起头，看着眼前的小男孩儿，脸一下子红了。她不敢相信似的问小男孩儿：“是送给我的吗？”小男孩儿回答：“是送给你的！”说这话时，他一脸的笑。“为什么要送给我花？”年轻的女老师有些奇怪，因为“三八妇女节”早就过了呀。“不为什么，就是想送给你。”


Q1：小男孩大概多大？他拿着什么来到办公室？
小男孩十岁左右。他捧着一大把玫瑰来到办公室。
Q2：女老师为什么觉得奇怪？
因为三八妇女节已经过去了，小男孩却送她花。

办公室的老师们都笑了起来。小男孩儿有些不好意思了，不明白老师们为什么会笑。一个女老师逗他：“那你为什么不送花儿给我呢？我也想要啊！”“可以呀，我捡了好多呢！”他认真地说：“等着，看我的！”小男孩儿又跑了出去。


Q3：女老师跟小男孩开了什么玩笑？小男孩怎样回答？
女老师问他为什么不送花给自己。小男孩说可以，他捡了很多，然后跑出去拿花。

原来是捡的啊！我拿过那把花儿仔细，每朵花儿都用玻璃纸包了，裹了又包，过玻璃纸，只见里面的绿叶子有些发黄。也许是花店卖剩的，也许是们丢掉的，但花儿还是很漂亮。


Q4：花是从哪里来的？叶子有什么样子？
花是捡来的，可能是花店剩下或者别人丢掉的。花的绿叶有一点发黄。

不一会儿，小男孩儿又抱来一大捧红红的玫瑰花，他往每个老师的办公桌上放了两朵。我们把花儿插在瓶子里，顿时，办公桌上冒出一玫瑰，给房间里带来了的春天的。每个老师都地笑了，快乐像春天的阳光照在每个人心里……


Q5：小男孩回来以后做了什么？
小男孩抱来很多玫瑰花，给每位老师桌上放两朵花。
Q6：老师们的心情怎么样？
老师们都很开心，心里感受到了快乐。

玫瑰花在办公室里开放了两个星期，大家把花儿扔掉。那些日子里，每个老师都被快乐着。原来，有时候，美丽和快乐也能凭这种得到。只要你能像小男孩儿那样它，像老师们那样接受它。


Q7：玫瑰花在办公室开了多久？
玫瑰花在办公室开放了两个星期。
Q8：大家为什么舍不得把花丢掉？
因为这束花带来了快乐，大家都被快乐包围着。
Q9：快乐只能用钱买到吗？课文告诉我们什么？
快乐不一定需要花钱。珍惜和接受，我们也可以得到美丽和快乐。
Q10：小男孩送的花是花钱买的吗？你觉得小男孩是怎样的孩子？
花不是买的，是捡来的。小男孩善良、单纯，愿意分享美好。
Q11：生活里，你得到过不用花钱的快乐吗？简单说一说。
开放题，没有标准答案。例如朋友的关心、看到好看风景等。

1. 数量短语：……左右（大约）

放在数字后面，表示大概的时间、年龄、数量。

例句：十岁左右；三点左右；五百块钱左右。

填空：他三十____。
他三十左右。
2. 动词+过来 / 过去（趋向补语）

表示人或者物体向说话人方向移动。走到身旁、拿过来、跑过去。

例句：他走到我身旁。请把书拿过来。

填空：请走____这里。
请走过来这里。
3. 似的 shìde（比况助词）

格式：像 / 好像 + 事物 + 似的，用来比喻。

例句：脸一下子红得像苹果似的。

填空：他跑得____兔子____。
他跑得像兔子似的。
4. 早就（副词）

表示事情在很早以前已经完成。

例句：节日早就过去了。我早就知道这件事。

填空：电影____结束了。
电影早就结束了。
5. 不为什么，就是……（口语惯用）

没有特别的理由，单纯心里想做。

例句：不为什么，就是想跟你聊天。

填空：不为什么，____想看看你。
不为什么，就是想看看你。

1. 起来（趋向补语）

动作开始或者出现某种状态：笑起来、跑起来、热起来。

例句：大家都笑了起来。天气冷起来了。

填空：孩子们开心地唱____。
孩子们开心地唱起来。
2. 有些 + 形容词（程度表达）

表示“有一点”，程度不高。有些不好意思、有些奇怪。

例句：我有些累。他有些生气。

填空：今天我____难过。
今天我有些难过。
3. 为什么不……呢？（反问句，提建议）

口语反问，用来提出建议。

例句：为什么不试一试呢？为什么不休息呢？

填空：____不试一试____？
为什么不试一试呢？
4. 看我的！（口语固定短句）

意思：你看我来做，我可以做好。

例句：等着，看我的！这件事交给我，看我的！

填空：等着，____！
等着，看我的！

1. 是……的 句式（强调来源、时间、方式）

强调信息，不是简单陈述事实。花儿是捡来的。

例句：这本书是网上买的。他是昨天来的。

填空：这件礼物，我____朋友送____。
这件礼物，我是朋友送的。
2. 动词+了又+动词（动作重复）

裹了又包、看了又看、想了又想，表示动作重复做。

例句：他想了又想，最后决定不去。

填空：他看____看，还是没看懂。
他看了又看，还是没看懂。
3. 也许……也许……（两种猜测并列）

对事情做两种可能性推测。

例句：他也许在家，也许在外面。

填空：明天____下雨，____刮风。
明天也许下雨，也许刮风。
4. 但（连词），表转折

跟“但是”一样，书面、口语都能用。虽然……但……

例句：东西不贵，但很好用。

填空：房间不大，____很干净。
房间不大，但很干净。

1. 不一会儿（时间短语）

很短时间以后，没过多久。

例句：不一会儿，雨就停了。

填空：____，他就回来了。
不一会儿，他就回来了。
2. 顿时（副词）

一件事情发生之后，立刻产生变化。

例句：听到好消息，他顿时笑了。灯一亮，房间顿时明亮。

填空：听到这句话，我____明白了。
听到这句话，我顿时明白了。
3. 给……带来了……（常用句式）

某人、某物带来某种东西或者感受。

例句：朋友给我带来了礼物。春天给城市带来绿色。

填空：阳光____我们____温暖。
阳光给我们带来了温暖。
4. A像B……（比喻句）

把A比作B。快乐像春天的阳光。

例句：月亮像圆盘。孩子像小鸟。

填空：白云____棉花。
白云像棉花。

1. 被字句：受事 + 被 + 施事 + 动词

每个老师都被快乐包围着。表示被动。

例句：杯子被弟弟打碎了。我被这件事感动。

填空：他____大家____感动了。
他被大家给感动了。
2. 原来（副词），表示发现真相

恍然大悟，知道真实情况。原来，快乐可以这样得到。

例句：原来你在这里！原来他不会汉语。

填空：____，这本书是你的。
原来，这本书是你的。
3. 凭……（介词，依靠、借助）

凭这种方式得到；凭努力取得成功。

例句：他凭自己的能力找到工作。

填空：他____努力获得成功。
他凭努力获得成功。
4. 只要……，就……（条件复句）

满足前面条件，就会出现后面结果。

例句：只要认真练习，就可以进步。

填空：____你坚持，____可以学好。
只要你坚持，就可以学好。
5. 像A那样，像B那样（举例参照）

格式：像+人/事+那样，用来参照别人的行为。

例句：像他那样努力，像老师那样思考。

填空：____你哥哥____，认真学习。
像你哥哥那样，认真学习。
